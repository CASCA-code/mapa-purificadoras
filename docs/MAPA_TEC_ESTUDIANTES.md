# Mapa Tec · estudiantes / deptos + agua

URL: https://casca-code.github.io/mapa-purificadoras/tec/

## Alcance
- Foco: **Tecnológico de Monterrey Campus Monterrey** (~2 km) + buffer **Tec Milenio Las Torres**.
- Capas: edificios `building=apartments` (OSM), Oxxo, Super7/7-Eleven, purificadoras (DENUE escaso + OSM casi vacío).
- Al tocar un depto: ficha con niveles/flats si existen; **población = desconocida**.

## Limitación honesta
Las purificadoras de barrio cerca del Tec **casi no están mapeadas en OSM**. El DENUE del estudio v2 (colonias gated) casi no cubre esta zona. Siguiente paso: recorrido de campo o consulta DENUE por coordenada con token.
