Sesión

    Aún no hay pines. Camina y pulsa M / S (primarios) u otras teclas.

    Cada pin/comentario se guarda al momento en las mismas keys que el mapa (purificadoras_field_adds_v1 / purificadoras_anclas_v1) + upsert ntfy. Export es respaldo.

    Google Maps API key

    Google Cloud billing requerido (hold ~$500 MXN). Para scout sin API key usa el userscript Tampermonkey — docs/SCOUT_USERSCRIPT.md. Si igual usas esta página: Maps JavaScript API + Street View; key en localStorage.purif_gmaps_key o ?key=.

    Ver docs/SCOUT_SV.md · ToS: human-in-the-loop.
